### Добавлено
- **Ops-мониторинг (MVP-9):** heartbeat-пинг в отдельный Telegram-канал + алерты при деградации источников (мёртвые источники)

## 2026-05-05

### Добавлено
- **Лемматизация (MVP-1):** токенизатор использует pymorphy3 — "повысил" / "повышение" / "повышению" распознаются как одна форма
- **Синонимы (MVP-2):** нормализация синонимов в токенизаторе — "ЦБ" = "Центробанк" = "Банк России"
- **Admin API (MVP-7):** REST CRUD для управления `rss_sources` без правки кода и перезапуска
- **Расширение источников (MVP-6):** с 5 до 13 RSS-источников + скрипт `check_feeds` для проверки доступности

### Улучшено
- **Near-dedup (MVP-5):** пул дедупликации ограничен 1000 строками через `ORDER BY seen_at DESC` — O(1) вместо O(N)
- **Атомарность (MVP-4):** cluster + dedup.record() объединены в одну транзакцию; добавлена система резервного копирования БД
