# Потенциал развития

## Ближайший горизонт (MVP+)

- Добавить 15–20 источников: региональные, отраслевые, Telegram-каналы через RSS-прокси
- Заменить SQLite на PostgreSQL → горизонтальное масштабирование и нормальная конкурентность
- Векторные эмбеддинги (sentence-transformers) вместо containment-алгоритма → точный clustering без стемминга
- Стемминг через pymorphy2 → "повысил" / "повышение" / "повышению" будут одним токеном
- Словарь синонимов: "ЦБ" = "Центробанк" = "Банк России" → меньше false negatives в clustering

## Средний горизонт (v2)

- **Тикерная привязка:** из события автоматически извлекать $GAZP, $SBER и т.д.
- **Портфельные уведомления:** пользователь подписывается на конкретные бумаги → "это событие касается твоего портфеля"
- **Исторические корреляции:** "санкции на нефть → в прошлом акции нефтяников -3.2% в течение дня" — статистически подкреплённый market impact
- **Admin API:** CRUD для rss_sources без правки кода и перезапуска
- **Мониторинг / алертинг:** heartbeat в отдельный канал, внешний uptime-monitor при деградации источников

## Долгий горизонт (v3+)

- **Signal aggregator:** из потока новостей генерировать торговые сигналы с P/L backtest
- **RAG-аналитика:** "объясни контекст этого события на основе последних 30 дней новостей"
- **Multi-modal:** скрины графиков цен + текст в одном посте при публикации события
- **API для внешних клиентов:** REST / WebSocket stream событий → интеграция с торговыми терминалами
- **Персонализация:** разные каналы для разных секторов (нефть, банки, металлы)

## Архитектурный эволюционный путь

```
Сейчас:  SQLite + APScheduler + Telegram Bot
v2:      PostgreSQL + Redis PubSub + WebSocket dashboard
v3:      Kafka / Redpanda + микросервисы (ingest / score / publish / analytics)
```

## Технические долги (исправить в первую очередь)

- Стемминг в clusterer — сейчас "повысил" ≠ "повышение", реальные false negatives
- AI-анализ блокирует публикацию до 15с — нужен fire-and-forget + editMessageText
- Near-dedup O(N) без индекса — при 20+ источниках замедлит весь цикл
- Шаги clusterer + dedup.record() не атомарны — нужна транзакция в orchestrator._run()
