# Design: Interactive Bot — Phase 3 UX

_Дата: 2026-05-25_
_Сессия: брейншторминг — интерактивный бот, онбординг, главное меню_

---

## 1. Цель

Сделать бота интерактивным: провести нового пользователя через настройку шаг за шагом (wizard) и дать постоянный доступ к разделам через главное меню.

---

## 2. Подход

**Wizard через inline-кнопки без состояния в БД.**

Шаг онбординга закодирован в `callback_data` кнопки (`onb:start`, `onb:2`, `onb:score:30` и т.д.). Никаких новых колонок в БД не требуется. Подход органично вписывается в существующий стиль кода (accordion в `/portfolio`).

---

## 3. Onboarding Wizard

### Определение нового vs вернувшегося пользователя

- **Новый** — нет тикеров в `portfolio_subscriptions` → показываем wizard
- **Вернувшийся** — есть тикеры → «С возвращением! Портфель: $SBER · $GAZP...» + inline-меню + ReplyKeyboardMarkup `[☰ Меню]` (на случай если кнопка пропала)

### Шаги wizard

**Шаг 1 — Приветствие**
```
Привет, {name}! Я MOEX.news — бот для инвесторов.

📡 Слежу за 15+ источниками и присылаю важные новости
по российскому рынку прямо в личку.

Настроим бота под тебя — займёт 1 минуту.

[Начать настройку 🚀]   callback: onb:start
```

**Шаг 2 — Портфель**
```
📋 Шаг 1 из 3 — Портфель

Выбери тикеры для личных алертов.
Когда выйдет важная новость — сразу напишу.

[accordion keyboard тикеров]
[✔️ Готово →]   callback: onb:2
```
Reuse `_build_keyboard(subscribed, done_callback="onb:2")` — добавить параметр `done_callback` в существующую функцию.

**Шаг 3 — Порог важности**
```
📊 Шаг 2 из 3 — Порог важности

Каждой новости я ставлю оценку от 0 до 100 —
насколько она важна для рынка.

• 10 — много новостей, в том числе мелкие
• 30 — только заметные события (рекомендую)
• 50 — только крупные: санкции, решения ЦБ, отчёты

[10] [20] [✅ 30] [50] [70]
[Пропустить →]

callbacks: onb:score:{value}, onb:skip:score
```

**Шаг 4 — Тихие часы**
```
🌙 Шаг 3 из 3 — Тихие часы

Алерты ночью? В тихие часы уведомления
не придут (время UTC).

[Выкл] [22–08] [23–08] [23–09]
[Пропустить →]

callbacks: onb:quiet:off, onb:quiet:22:8, onb:quiet:23:8, onb:quiet:23:9, onb:skip:quiet
```

**Шаг 5 — Готово**
```
🎉 Всё готово!

Подписан на {N} тикеров · Порог: {score} · Тихие часы: {quiet}

Теперь я буду присылать важные новости по твоим акциям.
Управляй ботом через кнопку ☰ Меню внизу.

→ ReplyKeyboardMarkup появляется: [☰ Меню]
```

### Callback routing — новые prefixes

| callback_data | Действие |
|---|---|
| `onb:start` | Показать шаг 2 (портфель) |
| `onb:2` | Сохранить тикеры, показать шаг 3 (порог) |
| `onb:score:{v}` | Сохранить порог v, показать шаг 4 |
| `onb:skip:score` | Оставить дефолт (30), показать шаг 4 |
| `onb:quiet:{from}:{to}` | Сохранить тихие часы, показать шаг 5 |
| `onb:skip:quiet` | Оставить дефолт (выкл), показать шаг 5 |

## 4. Главное меню

### Reply keyboard (постоянная)

Устанавливается один раз на шаге 5 wizard. Остаётся навсегда.

```
[☰ Меню]   ← ReplyKeyboardMarkup, resize_keyboard=True
```

### Inline-меню (по нажатию ☰ Меню)

Обычный пользователь:
```
📊 MOEX.news

[📋 Портфель]   [📅 Календарь]
[⚙️ Настройки]  [ℹ️ Помощь]
```

Админ (user_id ∈ ADMIN_USER_IDS):
```
📊 MOEX.news

[📋 Портфель]   [📅 Календарь]
[⚙️ Настройки]  [ℹ️ Помощь]
[📊 Статус]
```

### Callback routing — меню

| callback_data | Действие |
|---|---|
| `menu:portfolio` | То же что `/portfolio` |
| `menu:calendar` | То же что `/calendar` |
| `menu:settings` | То же что `/settings` |
| `menu:help` | Текст справки |
| `menu:status` | То же что `/status` (только админ) |

Обработчик текста `"☰ Меню"` добавляется в `handle_update` — до блока обработки команд.

## 5. Команда /help

```
ℹ️ MOEX.news — справка

Я слежу за новостями российского рынка и присылаю
важные события по твоим акциям.

📋 Портфель — /portfolio
Выбери тикеры ($SBER, $GAZP...). Когда выйдет
важная новость — получишь личный алерт.

📅 Календарь — /calendar
Ближайшие дивиденды, отчёты и оферты по

Порог важности (фильтр новостей) и тихие часы.

📡 Канал
Все значимые новости публикуются в общем канале.
```

## 6. Изменения существующего кода

### `app/bot/commands.py`

| Что | Изменение |
|---|---|
| `_welcome()` | Рефактор: новый пользователь → wizard, вернувшийся → меню |
| `_build_keyboard()` | Добавить параметр `done_callback: str = "done"` |
| `handle_update()` | Добавить handler текста `"☰ Меню"` перед cmd-блоком |
| `_handle_callback()` | Добавить ветки `onb:*` и `menu:*` |
| `_handle_help()` | Новая функция, текст справки |
| `_build_main_menu_keyboard()` | Новая функция, inline-меню |
| `_send_menu()` | Новая функция, отправляет inline-меню |

### `app/telegram/client.py`

| Что | Изменение |
|---|---|
| `send_dm()` | Добавить параметр `set_reply_keyboard: bool = False` — когда True, вместе с сообщением устанавливает ReplyKeyboardMarkup `[☰ Меню]` |

### Регистрация команд Telegram (`setMyCommands`)

Вызов при старте сервиса (в `main.py` или `runner.py`):
```
/portfolio — Мой портфель
/calendar  — Ближайшие события
/settings  — Настройки
/help      — Помощь
```

### БД

Изменений схемы нет.

## 7. Обработка edge cases

| Ситуация | Поведение |
|---|---|
| Текст во время wizard | «Используй кнопки для навигации 👆» |
| `/start` у вернувшегося пользователя | Приветствие + inline-меню (без wizard) |
| `/portfolio` без wizard | Работает как раньше, кнопка «Готово» = `done` |
| Пользователь нажал «Пропустить» на обоих шагах | Дефолты: порог=30, тихие часы=выкл |
| Меню для анонима (не /start) | Команды работают без wizard |
