# Product Roadmap — GeoSignal / Newsparser Bot

_Дата: 2026-05-23_
_Сессия: брейншторминг — подписка + роадмэп_

---

## 1. Что такое бот

Telegram-бот для частных инвесторов на российском рынке.

**Основные функции:**
- Агрегирует финансовые новости из RSS-лент (ТАСС, РБК, Интерфакс, Ведомости, BFM и др.) и Telegram-каналов
- Фильтрует нерелевантный шум, оставляя только события с рыночным значением (санкции, дивиденды, отчёты, M&A, решения ЦБ и т.д.)
- Публикует значимые события в общий Telegram-канал
- Отправляет личные алерты пользователям, подписанным на конкретные тикеры

**Текущие источники:** 14 RSS-лент + 5 Telegram-каналов  
**Текущий контент:** только новости (дивиденды/отчётности предстоит построить)

---

## 2. Целевая аудитория

**Основная:** частные инвесторы, следящие за российским фондовым рынком (MOEX)  
**Типичный пользователь:** держит портфель из 5–20 акций, хочет получать важные события без постоянного мониторинга новостных лент

---

## 3. Бизнес-модель — Freemium

### Почему freemium
- Снижает барьер входа: пользователь получает ценность бесплатно
- Органический рост: бесплатные пользователи становятся платными, когда видят ограничения

### Почему не задержка уведомлений
Новости приходят из RSS и Telegram-каналов — они уже вторичные источники (15–60 мин задержки от события). Добавлять искусственную задержку поверх = присылать неактуальные данные. Этот механизм монетизации отклонён.

### Ограничения тарифов

| | Бесплатный | Платный |
|---|---|---|
| Тикеры в портфеле | до **3** | **безлимит** |
| Новости | ✅ | ✅ |
| Дивидендный календарь | ❌ | ✅ |
| Отчётности (МСФО/РСБУ) | ❌ | ✅ |
| Изменения в составе ETF | ❌ | ✅ (будущее) |

**Логика ограничений:**
- 3 тикера достаточно, чтобы попробовать, но мало для серьёзного портфеля
- Дивиденды и отчётности — самый ценный контент для инвестора, создаёт чёткий стимул апгрейда

### Оплата
- Платёжная система: **ЮKassa** (рублёвые платежи)
- Ценовой диапазон: ~**499–699 ₽/мес** (уточнить при запуске)
- Управление подпиской: прямо в боте через команды

## 4. Roadmap — Вариант A (Продукт → Монетизация)

### Фаза 1: Стабильный бот _(текущая неделя)_

**Цель:** убедиться что новости доходят до пользователя

**Задачи:**
- [ ] Проверить в понедельник (первый торговый день): приходят ли новости в канал
- [ ] Проверить личные алерты по тикерам (DM от бота)
- [ ] Убедиться что `telegram_channel_id` настроен верно
- [ ] Зафиксировать баги и устранить

**Ожидаемый результат:** в понедельник утром 2–5 релевантных новостей уходит в канал

---

### Фаза 2: Дивиденды + Отчётности _(2–4 недели)_

**Цель:** добавить уникальный контент, которого нет в бесплатном режиме

#### 2а. Дивидендный календарь

**Источник данных:** MOEX API (`iss.moex.com`) — официальные данные по дивидендам  
**Что парсим:**
- Рекомендованный дивиденд (руб./акцию)
- Дата закрытия реестра (отсечка)
- Дата выплаты

**Форматы алертов:**
```
📅 Дивиденд: $SBER
💰 36 руб/акцию
📌 Дата отсечки: 15 июля 2026
💳 Выплата: 30 июля 2026
```

**Логика отправки:**
- За 7 дней до отсечки — предупреждение
- В день объявления (совет директоров рекомендовал) — мгновенный алерт

#### 2б. Отчётности (МСФО/РСБУ)

**Источники:**
- Уже ловятся через RSS (ключевые слова: `мсфо`, `рсбу`, `чистая прибыль`, `выручка`)
- Добавить специализированные: `e-disclosure.ru`, `раскрытие.рф`

**Формат алерта:**
```
📊 Отчётность: $GAZP (МСФО 1П2026)
📈 Выручка: 4.2 трлн руб (+12% г/г)
💰 Чистая прибыль: 890 млрд руб (+8% г/г)
```

---

### Фаза 3: Полировка UX + Онбординг _(1–2 недели)_

**Цель:** бот понятен новому пользователю без объяснений

**Задачи:**
- [ ] Переработать `/start` — короткий понятный онбординг
- [ ] Команда `/help` — описание всех возможностей
- [ ] Команда `/calendar` — ближайшие дивиденды и отчёты по портфелю
- [ ] Ежедневный дайджест (опционально: утром топ-5 событий за вчера)
- [ ] Красивое форматирование сообщений

---

### Фаза 4: Подписка + ЮKassa _(2–3 недели)_

**Цель:** первая монетизация

**Задачи:**

**Ограничения free tier:**
- [ ] Лимит 3 тикера в `/portfolio`
- [ ] Скрыть дивиденды/отчётности для бесплатных пользователей

**Платёжная интеграция:**
- [ ] Регистрация в ЮKassa, получение API-ключей
- [ ] Команда `/subscribe` — выбор плана, переход к оплате
- [ ] Webhook от ЮKassa → активация подписки в БД
- [ ] Команда `/billing` — статус подписки, история платежей, отмена
- [ ] Автопродление / уведомление об истечении

**Таблицы БД:**
```sql
subscriptions (user_id, plan, started_at, expires_at, status)
payments (user_id, amount, provider_id, status, created_at)
```
