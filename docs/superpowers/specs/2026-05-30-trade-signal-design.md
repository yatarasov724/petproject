# Trade Signal DM Design

**Date:** 2026-05-30  
**Status:** Approved

## Problem

Пользователи получают новости с AI-анализом, но не понимают что с этим делать. Информация о событии есть, но нет ответа на вопрос "мне купить или продать?".

## Goal

Розничный инвестор, у которого тикер из новости есть в портфеле, получает в личку конкретное действие с кратким обоснованием — краткосрочно и долгосрочно.

---

## Delivery

Только личное сообщение (DM) пользователям, у которых тикер подписан в портфеле. Основной канал не меняется.

---

## Signal Format

```
📊 *$SBER* — ЦБ повысил ставку до 21%

⏱ *Краткосрочно:* 🔴 Продавать
По истории: −3.2% за сутки после подобных новостей

📅 *Долгосрочно:* 🟡 Держать
Цикл ужесточения временный, банк адаптируется к ставке

⚠️ _Не является инвестиционной рекомендацией_
```

**Направление сигнала:** 🟢 Покупать / 🔴 Продавать / 🟡 Держать

**Если несколько тикеров в событии** — один DM, заголовок: `$SBER · $VTBR`

**Если исторических данных нет** — краткосрочный блок: `🟡 Держать _(недостаточно данных)_`

**Если AI недоступен** — долгосрочный блок опускается целиком

---

## Signal Generation Logic

### Краткосрочный сигнал (горизонт ~24ч)

Источник: `price_snapshots` — исторические движения цены после событий того же `event_type` + тикер.

Пороги (на основе `avg_24h_pct`):
- < −1.5% → 🔴 Продавать
- > +1.5% → 🟢 Покупать
- иначе → 🟡 Держать

Fallback (если данных < 3 наблюдений): используется `ai_analysis.impact`:
- `negative` → 🔴 Продавать
- `positive` → 🟢 Покупать

Описание: `"По истории: {avg_24h_pct:+.1f}% за сутки после подобных новостей"` (если есть данные) или `"_(недостаточно данных)_"`.

### Долгосрочный сигнал (горизонт недели/месяц)

Источник: отдельный AI-вызов (~50 токенов). Промпт передаёт заголовок новости + тип события + краткосрочный сигнал. AI возвращает направление (buy/sell/hold) + одно предложение-обоснование.

## New Components

### `app/ai/signal.py` (новый файл)

```python
@dataclass
class TradeSignal:
    short_direction: str   # "buy" | "sell" | "hold"
    short_reason: str      # human-readable description
    long_direction: str    # "buy" | "sell" | "hold"  (пустая строка если AI недоступен)
    long_reason: str       # AI one-liner (пустая строка если AI недоступен)
```

`build_signal(correlations, ai_analysis, title, event_type) -> TradeSignal`

- Считает краткосрочный сигнал из `correlations` (список `CorrelationResult` уже есть в `orchestrator.py`)
- Вызывает AI для долгосрочного сигнала (отдельная async-функция `_ai_long_term`)
- Fallback-safe: любой сбой → `long_direction = ""`, `long_reason = ""`

### `app/telegram/formatter.py` (изменение)

Новая функция `format_trade_dm(title, tickers, signal) -> str` — форматирует DM в MarkdownV2.

### `app/bot/portfolio.py` (изменение)

`notify_with_ai()` вызывает `build_signal()` и отправляет DM через `format_trade_dm()` вместо текущего формата.

---

## What Does NOT Change

- Основной Telegram-канал и формат публикаций
- Пайплайн (orchestrator, scorer, clusterer, publish_decision)
- Схема БД — новых таблиц нет
- Существующий fallback DM без AI (функция `notify()` остаётся)
